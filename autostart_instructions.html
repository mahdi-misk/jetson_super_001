خطوات تشغيل نظام RoadVision-AI تلقائياً عند إقلاع الـ Jetson

لجعل النظام يعمل كخدمة (Service) في الخلفية مباشرة أول ما تشتغل شريحة الـ Jetson، يرجى فتح نافذة الأوامر (Terminal) واتباع الخطوات التالية بدقة:

1. نسخ ملف الخدمة إلى مجلد خدمات النظام

قم بنسخ ملف الخدمة الذي تم إنشاؤه مسبقاً إلى مجلد النظام عبر الأمر التالي:

sudo cp /home/mahdi/jetson_super_001/roadvision.service /etc/systemd/system/

2. تحديث قائمة الخدمات

لإخبار النظام بأن هناك خدمة جديدة تمت إضافتها، نفذ الأمر:

sudo systemctl daemon-reload

3. تفعيل الخدمة لتعمل تلقائياً عند التشغيل

هذا الأمر هو الذي يربط الخدمة ببدء تشغيل النظام:

sudo systemctl enable roadvision.service

4. بدء تشغيل الخدمة الآن (اختياري)

إذا أردت تشغيل النظام فوراً في الخلفية بدون الحاجة لإعادة تشغيل الـ Jetson:

sudo systemctl start roadvision.service

أوامر مفيدة للتحكم بالنظام مستقبلاً:

  • لإيقاف النظام مؤقتاً:
    sudo systemctl stop roadvision.service

  • لإعادة تشغيل النظام:
    sudo systemctl restart roadvision.service

  • لمشاهدة سجلات النظام (Log) للتأكد من عمله أو رؤية الأخطاء:
    sudo journalctl -u roadvision.service -f
